1. What is Unsupervised Learning?

Finding hidden structure in unlabeled data — no target variable y is provided.

In supervised learning we have (X, y) — labeled pairs. In unsupervised learning we only have X — no labels. The algorithm must discover structure on its own.

Three Main Paradigms

Dimensionality ReductionCompress features while preserving structurePCA, t-SNE, UMAP, Autoencoders
Association RulesFind co-occurrence patterns in transactionsApriori, FP-Growth
Anomaly DetectionIdentify rare unusual data pointsIsolation Forest, LOF, One-Class SVM

Supervised vs Unsupervised

2. K-Means Clustering

Clustering

Partition data into K clusters by iteratively assigning points to nearest centroid and recomputing centroids.

When to use: Known (or estimable) K. Clusters are roughly spherical and similarly sized. Large datasets — very fast. Customer segmentation, document clustering, image compression.
Avoid when: Clusters are non-spherical, elongated, or irregular. Clusters have very different sizes or densities. Number of K truly unknown (use Elbow + Silhouette to estimate it).

Algorithm Steps

1. Initialise K centroids (K-Means++ default — smarter than random) 2. Assign each point to the nearest centroid (Euclidean distance) 3. Recompute each centroid = mean of all points in that cluster 4. Repeat steps 2–3 until centroids stop moving (convergence)

K-Means Iteration Diagram

How to interpret results:
• Inertia: total within-cluster sum of squares. Lower = tighter clusters. Use Elbow plot to choose K.
• Silhouette score: -1 to 1. > 0.5 = well-defined clusters. Peak value = best K.
• Cluster profiles: compute mean of each feature per cluster → gives business meaning to each segment.
• Centroids: the "average member" of each cluster — useful for describing customer archetypes.
Real-world use cases:
• GTBank / UBA: Customer segmentation by spending behaviour and account activity
• Jumia: Product grouping for recommendation engine
• Lagos State Government: Neighbourhood profiling for resource allocation
• MUSC Health: Patient cohort identification from ED visit patterns
• Dangote: Supply chain route clustering by distance and delivery frequency
Python · K-Means · Elbow + Silhouette + Cluster Profiles
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import pandas as pd, numpy as np

# Scale first — K-Means uses Euclidean distance
scaler = StandardScaler()
X_sc = scaler.fit_transform(X)

# Elbow + Silhouette to find best K
k_range    = range(2, 11)
inertias   = []
sil_scores = []
for k in k_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_sc)
    inertias.append(km.inertia_)
    sil_scores.append(silhouette_score(X_sc, labels))

best_k = list(k_range)[np.argmax(sil_scores)]
print(f"Best K = {best_k} | Silhouette = {max(sil_scores):.4f}")

# Fit final model
km_final = KMeans(n_clusters=best_k, random_state=42, n_init=10)
df['Cluster'] = km_final.fit_predict(X_sc)

# Cluster profiles (mean per cluster)
profile = df.groupby('Cluster').mean().round(2)
print(profile)

# Predict new point
new_point = scaler.transform([[value1, value2, ...]])
cluster   = km_final.predict(new_point)
print(f"New customer belongs to Cluster {cluster[0]}")

3. Hierarchical Clustering

Clustering

Builds a tree of clusters (dendrogram) — cut at any level to get any number of clusters.

When to use: You do not know K in advance. Small to medium datasets (< 10,000 points). You want to visualize the full cluster hierarchy. Biological taxonomy, document hierarchies, gene expression.

Dendrogram Diagram

Linkage Methods

LinkageDistance between clustersEffect
wardMinimizes within-cluster varianceCompact, equal-size clusters (most common)
completeMaximum distance between any two pointsCompact, similar-size clusters
averageAverage distance between all pairsBetween ward and single
singleMinimum distance between any two pointsChaining effect — elongated clusters

4. DBSCAN

ClusteringAnomaly Detection

Density-based clustering — finds clusters as dense regions, automatically identifies outliers as noise.

When to use: Arbitrary cluster shapes (moons, rings, elongated). Do not know K in advance. Outlier detection is important. Spatial / geographic data.

Core / Border / Noise Point Diagram

Core point: has ≥ min_samples neighbours within radius ε Border point: within ε of a core point but fewer than min_samples neighbours Noise point: not within ε of any core point → labelled -1 (outlier)

Hyperparameter Guide

ParameterMeaningHow to choose
eps (ε)Maximum distance between two neighboursk-distance graph elbow (k = min_samples)
min_samplesMinimum points to form a core pointRule of thumb: 2 × n_features, minimum 5
How to interpret results:
• Labels -1 = noise/outliers — not belonging to any cluster.
• Number of clusters: len(set(labels)) - (1 if -1 in labels else 0)
• High noise count → eps too small or min_samples too high. Reduce eps or min_samples.
Python · DBSCAN · eps Selection + Fitting
from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
import numpy as np

# Step 1: Choose eps with k-distance graph
k = 5   # usually = min_samples
nbrs = NearestNeighbors(n_neighbors=k).fit(X_sc)
distances, _ = nbrs.kneighbors(X_sc)
k_dist = np.sort(distances[:, k-1])[::-1]

# Plot k_dist vs index — elbow = suggested eps
# plt.plot(k_dist); plt.xlabel('Points'); plt.ylabel(f'{k}-NN dist'); plt.show()

# Step 2: Fit DBSCAN
db = DBSCAN(eps=0.3, min_samples=5)
labels = db.fit_predict(X_sc)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise    = (labels == -1).sum()
print(f"Clusters found: {n_clusters}")
print(f"Noise points:   {n_noise} ({n_noise/len(labels):.1%})")

# Anomaly extraction — noise points are potential outliers
outlier_indices = np.where(labels == -1)[0]
X_outliers = X_sc[outlier_indices]

# Silhouette (exclude noise for fair comparison)
mask = labels != -1
if mask.sum() > 0 and len(set(labels[mask])) > 1:
    from sklearn.metrics import silhouette_score
    sil = silhouette_score(X_sc[mask], labels[mask])
    print(f"Silhouette (excl. noise): {sil:.4f}")

5. Gaussian Mixture Models (GMM)

Clustering

Probabilistic soft clustering — each point has a probability of belonging to each component. Handles elliptical clusters.

When to use: Clusters may be elliptical or have different orientations. Soft (probabilistic) cluster memberships needed. Data comes from mixed distributions. Density estimation required.

K-Means vs GMM

FeatureK-MeansGMM
AssignmentHard (one cluster only)Soft (probability of each cluster)
Cluster shapeSpherical onlyElliptical (flexible covariance)
OutputCluster labelProbability distribution
AlgorithmLloyd's (iterative means)EM (Expectation-Maximization)
Choose KElbow / SilhouetteBIC or AIC (lower = better)
How to interpret results:
• predict_proba(X): gives probability of each cluster for every point.
• BIC / AIC: choose K with minimum BIC (more conservative) or AIC (less conservative).
• covariance_type='full': most flexible — allows ellipses of any shape and orientation.
• score(X): log-likelihood — higher = better model fit.
Python · GMM · BIC Selection + Soft Probabilities
from sklearn.mixture import GaussianMixture

# Choose K using BIC
bic_scores = []
for k in range(1, 9):
    gmm = GaussianMixture(n_components=k, covariance_type='full',
                          random_state=42, n_init=3)
    gmm.fit(X_sc)
    bic_scores.append(gmm.bic(X_sc))

best_k = range(1,9)[np.argmin(bic_scores)]
print(f"Best K by BIC: {best_k}")

# Fit best GMM
gmm_best = GaussianMixture(n_components=best_k,
                            covariance_type='full',
                            random_state=42, n_init=3)
gmm_best.fit(X_sc)

# Hard labels (most likely cluster)
labels_hard = gmm_best.predict(X_sc)
# Soft probabilities
labels_soft = gmm_best.predict_proba(X_sc)

print("Soft probabilities for first 3 points:")
print(labels_soft[:3].round(4))

# Log-likelihood (higher = better fit)
print(f"Log-likelihood: {gmm_best.score(X_sc):.4f}")

# Anomaly detection: flag low-probability points
log_proba = gmm_best.score_samples(X_sc)
threshold = np.percentile(log_proba, 5)  # bottom 5%
anomalies = log_proba < threshold
print(f"Anomalies detected: {anomalies.sum()}")

6. Principal Component Analysis (PCA)

Dimensionality Reduction

Finds directions of maximum variance in data and projects onto those axes. Linear, fast, interpretable.

When to use: Reduce dimensionality before training another model. Visualize high-dimensional data. Remove multicollinearity. Compress images or signals. Speed up training.
Avoid when: Need interpretable original features. Class discrimination matters more than variance (use LDA). Data has non-linear structure (use t-SNE or UMAP for visualization).

PCA Diagram — Variance Directions

How to interpret results:
• explained_variance_ratio_: % of total variance captured by each PC. Sum until 80–95%.
• Scree plot: bar chart of explained variance — choose n_components at the elbow.
• Loadings (components_): how much each original feature contributes to each PC.
• Reconstruction error: MSE between original and inverse-transformed data — lower = better.
Python · PCA · Full Analysis Pipeline
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np, pandas as pd

# Always scale before PCA
scaler = StandardScaler()
X_sc = scaler.fit_transform(X)

# Step 1: Fit PCA with all components to inspect variance
pca_full = PCA(random_state=42)
pca_full.fit(X_sc)

# Cumulative explained variance
cum_var = np.cumsum(pca_full.explained_variance_ratio_)
n_80 = np.argmax(cum_var >= 0.80) + 1   # components for 80%
n_95 = np.argmax(cum_var >= 0.95) + 1   # components for 95%
print(f"Components for 80% variance: {n_80}")
print(f"Components for 95% variance: {n_95}")

# Step 2: Fit PCA with chosen n_components
pca = PCA(n_components=n_95, random_state=42)
X_reduced = pca.fit_transform(X_sc)
print(f"Reduced shape: {X_sc.shape} → {X_reduced.shape}")

# Step 3: Reconstruction error
X_recon = pca.inverse_transform(X_reduced)
mse = np.mean((X_sc - X_recon)**2)
print(f"Reconstruction MSE: {mse:.4f}")

# Step 4: Feature loadings (which features dominate each PC)
loadings = pd.DataFrame(
    pca.components_.T,
    index=feature_names,
    columns=[f'PC{i+1}' for i in range(n_95)]
)
print("\\nTop contributing features to PC1:")
print(loadings['PC1'].abs().sort_values(ascending=False).head(5))

# Step 5: Visualize in 2D
pca_2d = PCA(n_components=2)
X_2d   = pca_2d.fit_transform(X_sc)
# plt.scatter(X_2d[:,0], X_2d[:,1], c=labels, cmap='tab10')

7. t-SNE

Dimensionality Reduction

Non-linear visualization method — preserves local neighbourhood structure. For 2D/3D plots only.

When to use: Exploring high-dimensional data visually (images, embeddings, genomics). Best 2D separation of complex clusters. After PCA to further refine visualization.
Critical limitations — t-SNE is for VISUALIZATION ONLY:
• Cannot transform new data — no out-of-sample projection.
• Inter-cluster distances are not meaningful — only within-cluster neighbourhood is preserved.
• Slow on large datasets — use PCA first to reduce to ~50 dims, then t-SNE.
• Always try multiple perplexity values — the output changes significantly.

Perplexity Guide

PerplexityFocusEffect
5–10Very localMany small tight clusters, fragmented view
30 (default)BalancedGood general-purpose starting point
50–100More globalLarger, smoother clusters

9. Autoencoders

Dimensionality ReductionAnomaly Detection

Neural network that compresses and reconstructs its own input. Bottleneck = learned representation. High reconstruction error = anomaly.

Architecture Diagram

How to use for anomaly detection:
1. Train autoencoder ONLY on normal/clean data.
2. Compute reconstruction error on all data (including test).
3. Set threshold at 95th–99th percentile of normal data's error.
4. Points with error above threshold = anomaly.
The model fails to reconstruct anomalies well because it never saw them during training.
Python · Autoencoder · Keras + Anomaly Detection
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
import numpy as np

# Build autoencoder
def build_autoencoder(input_dim, latent_dim=8):
    # Encoder
    encoder_input = keras.Input(shape=(input_dim,))
    x = layers.Dense(64, activation='relu')(encoder_input)
    x = layers.Dense(32, activation='relu')(x)
    latent = layers.Dense(latent_dim, activation='relu',
                           name='latent')(x)
    # Decoder
    x = layers.Dense(32, activation='relu')(latent)
    x = layers.Dense(64, activation='relu')(x)
    output = layers.Dense(input_dim, activation='linear')(x)

    autoencoder = keras.Model(encoder_input, output)
    autoencoder.compile(optimizer='adam', loss='mse')
    return autoencoder

ae = build_autoencoder(input_dim=X_train.shape[1], latent_dim=4)

# Train ONLY on normal data
history = ae.fit(
    X_normal_sc, X_normal_sc,   # target = input itself!
    epochs=50, batch_size=32,
    validation_split=0.1,
    callbacks=[keras.callbacks.EarlyStopping(patience=5)],
    verbose=0
)

# Compute reconstruction errors on all data
X_reconstructed = ae.predict(X_all_sc, verbose=0)
recon_error = np.mean((X_all_sc - X_reconstructed)**2, axis=1)

# Threshold at 95th percentile of normal errors
threshold = np.percentile(recon_error[:len(X_normal_sc)], 95)
predictions = (recon_error > threshold).astype(int)
print(f"Anomalies detected: {predictions.sum()}")
print(f"Threshold: {threshold:.4f}")

10. Association Rule Mining (Apriori / FP-Growth)

Association Rules

Discovers co-occurrence patterns in transactional data — "customers who buy X also buy Y."

When to use: Market basket analysis. Product recommendation engines. Cross-sell and upsell strategy. Pharmacy co-prescription analysis. Any domain with transactional data.

Key Concepts

Support(A→B) = P(A ∩ B) = transactions with both A and B / total transactions Confidence(A→B) = P(B|A) = P(A ∩ B) / P(A) — if A bought, probability B bought Lift(A→B) = Confidence / P(B) — how much more likely than by chance? Lift > 1 → positive association Lift = 1 → independent Lift < 1 → negative association

How to Interpret Rules

RuleSupportConfidenceLiftMeaning
Phone → Phone Case0.350.822.8Strong: buying phone → 82% buy case, 2.8× more likely
Laptop → Laptop Bag0.280.752.3Strong: buying laptop → 75% buy bag
T-Shirt → Jeans0.150.451.1Weak: only slightly better than chance
Focus on: High confidence + high lift rules. Support tells you how common the pair is. Confidence tells you how reliable the rule is. Lift tells you how much better than random.
Python · Apriori · Market Basket Analysis
# pip install mlxtend
from mlxtend.frequent_patterns import apriori, association_rules
from mlxtend.preprocessing import TransactionEncoder
import pandas as pd

# Transaction list
transactions = [
    ['Phone', 'Phone Case', 'Charger'],
    ['Laptop', 'Laptop Bag', 'Mouse'],
    ['Phone', 'Earphones', 'Screen Protector'],
    # ... more transactions
]

# Encode as boolean matrix
te = TransactionEncoder()
te_array = te.fit_transform(transactions)
df_trans  = pd.DataFrame(te_array, columns=te.columns_)

# Mine frequent itemsets
freq_items = apriori(df_trans,
                      min_support=0.05,     # 5% min frequency
                      use_colnames=True,
                      max_len=3)            # max 3 items

# Generate association rules
rules = association_rules(freq_items,
                          metric='lift',
                          min_threshold=1.2,
                          num_itemsets=len(freq_items))

# Sort by lift (strongest associations first)
rules = rules.sort_values('lift', ascending=False)

# Display top rules
top = rules[['antecedents','consequents',
             'support','confidence','lift']].head(10)
top['antecedents'] = top['antecedents'].apply(
    lambda x: ', '.join(list(x)))
top['consequents'] = top['consequents'].apply(
    lambda x: ', '.join(list(x)))
print(top.round(4).to_string(index=False))

# Actionable: Filter high-confidence rules for cross-sell
cross_sell = rules[(rules['confidence'] > 0.7) &
                   (rules['lift'] > 1.5)]
print(f"\\nHigh-value cross-sell rules: {len(cross_sell)}")

11. Anomaly Detection

Anomaly Detection

Identifies rare, unusual data points that differ significantly from the majority — no labels required.

Four Major Algorithms

AlgorithmApproachBest for
Isolation ForestAnomalies are easier to isolate — shorter path in random treesHigh-dimensional tabular, large datasets
Local Outlier Factor (LOF)Points in low-density regions relative to neighboursLower-dimensional, density-based outliers
One-Class SVMLearn boundary around normal data, flag outside pointsComplex boundary, small dataset
Elliptic EnvelopeFit multivariate Gaussian, flag statistical outliersNear-Gaussian data, few features
How to interpret results:
• Labels: -1 = anomaly, 1 = normal (sklearn convention).
• decision_function(X): anomaly score. More negative = more anomalous.
• contamination: expected fraction of outliers. Set to match domain knowledge (e.g. 0.02 for 2% fraud rate).
• Tune threshold on a labelled validation set if ground truth is available.
Real-world use cases:
• GTBank / First Bank: Credit card fraud detection (real-time transaction scoring)
• MUSC Health: Unusual patient vital signs in ED monitoring
• Dangote: Manufacturing defect detection from sensor readings
• UBA Compliance: AML suspicious transaction flagging
• Jumia: Fake product listing detection from listing features
• Network security: Intrusion detection system
Python · Anomaly Detection · Four Algorithms
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.covariance import EllipticEnvelope

# Contamination = expected fraction of anomalies
contamination = 0.05   # 5% fraud rate

# 1. Isolation Forest (best general-purpose)
iso = IsolationForest(contamination=contamination,
                       n_estimators=200,
                       random_state=42, n_jobs=-1)
labels_iso   = iso.fit_predict(X_sc)   # -1=anomaly, 1=normal
scores_iso   = iso.decision_function(X_sc)  # more negative = anomaly

# 2. Local Outlier Factor
lof = LocalOutlierFactor(contamination=contamination,
                          novelty=False)
labels_lof = lof.fit_predict(X_sc)
# For novel point prediction, use novelty=True and lof.predict()

# 3. One-Class SVM (train on normal data only)
ocsvm = OneClassSVM(nu=contamination)
ocsvm.fit(X_normal_sc)       # fit on normal only
labels_svm = ocsvm.predict(X_all_sc)

# 4. Elliptic Envelope
ee = EllipticEnvelope(contamination=contamination,
                       random_state=42)
labels_ee = ee.fit_predict(X_sc)

# Count anomalies
for name, labels in [('Isolation Forest', labels_iso),
                      ('LOF', labels_lof),
                      ('One-Class SVM', labels_svm),
                      ('Elliptic Envelope', labels_ee)]:
    n_anom = (labels == -1).sum()
    print(f"{name}: {n_anom} anomalies ({n_anom/len(labels):.1%})")

No ground truth labels — use internal metrics. Use external metrics only when labels are available for validation.

from sklearn.metrics import (
    silhouette_score, davies_bouldin_score,
    calinski_harabasz_score,
    adjusted_rand_score, normalized_mutual_info_score,
    homogeneity_score, completeness_score

def evaluate_clustering(X_sc, labels, y_true=None, name='Model'):
    """Full clustering evaluation report."""
    n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
    if n_clusters < 2:
        print(f"{name}: only {n_clusters} cluster — cannot evaluate"); return

    # Internal
    sil = silhouette_score(X_sc, labels)
    db  = davies_bouldin_score(X_sc, labels)
    ch  = calinski_harabasz_score(X_sc, labels)

    print(f"\\n{'='*50}")
    print(f"{name}")
    print(f"{'='*50}")
    print(f"  Clusters found:       {n_clusters}")
    print(f"  Silhouette Score:     {sil:.4f}  (↑ higher better, >0.5 = good)")
    print(f"  Davies-Bouldin:       {db:.4f}   (↓ lower better)")
    print(f"  Calinski-Harabasz:    {ch:.1f}   (↑ higher better)")

    # External (if labels available)
    if y_true is not None:
        ari  = adjusted_rand_score(y_true, labels)
        nmi  = normalized_mutual_info_score(y_true, labels)
        hom  = homogeneity_score(y_true, labels)
        comp = completeness_score(y_true, labels)
        print(f"  Adjusted Rand Index:  {ari:.4f}  (↑ higher better)")
        print(f"  Normalized Mutual Info: {nmi:.4f}")
        print(f"  Homogeneity:          {hom:.4f}")
        print(f"  Completeness:         {comp:.4f}")

    return {'sil': sil, 'db': db, 'ch': ch}

km = KMeans(n_clusters=4, random_state=42, n_init=10)
labels = km.fit_predict(X_sc)

                               y_true=y_true,   # optional
